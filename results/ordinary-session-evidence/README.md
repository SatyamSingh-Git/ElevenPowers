## Model-free rehearsal

```sh
python -m eval.advice_delivery NEW_DISPOSABLE_DIRECTORY --ordinary-prompts
```

This opens each task through its host's prompt callback with `Read EXERCISE.md
and follow its instructions.` No controller-created task ID is used. Real
Python and JavaScript commands fail, pass, regress, interrupt and recover through
all five replay/synthetic-native launchers. Follow-up states and task continuity
are checked separately from process exits. Runtime/producer/test hashes bind the
observations. No model calls, model-comprehension or installed-acceptance claim
is made. The [fresh matrix](matrix.json) qualified all **20/20** cells at the final runtime
fingerprint in **251.844 seconds** of summed local exercise time. Each native
cell retained current, failed, incomplete and current follow-up states; every
replay stayed unobserved. All tasks opened through the prompt, with no invented
claims, and preserved identity through the edit.

## Installed qualification

Prepared sealed exercises launch no model. A fresh subscription allowance is
required before new installed sessions; earlier approved runs and their outcomes
remain in [the installed archive](../advice-delivery/installed-2026-10-11/README.md).
The next exercises deliberately retain the ordinary claim-less opening prompt.
They qualify callback capture and advice observations, not a causal improvement
in coding outcomes. Unavailable, denied and incomplete attempts remain explicit.
