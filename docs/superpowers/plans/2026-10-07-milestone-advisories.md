# Milestone advisory implementation plan

**Goal:** qualify larger-project recheck advice and deliver bounded optional
context through the shared edit lifecycle. Execute inline and push ten coherent
changes as they pass their controls. Spec: [bounded advice](../../design/milestone-advisories.md).

**Constraints:** generalized runtime; no paid runs; no new gate; no discarded
fallback checks; preserve provenance, incomplete work and frozen references.

1. Commit this design, plan and frozen acceptance policy. Inspect pinned upstream
   source before labelling consumers and unrelated checks.
2. Exercise existing declared process relationships with a real failing and
   equivalent command control; document the supported portable declaration.
3. Add a sealed larger-project evaluator. Observe missing/invalid corpus
   controls red before implementing grading and source verification.
4. Run the evaluator on frozen upstream snapshots; publish raw observations,
   hashes, misses, unknown candidates and timings without coding-benefit claims.
5. Add strict advisory policy and bounded context rendering, with red/green
   controls for malformed limits, omission, fallback and credential redaction.
6. Add atomic reservations, deduplication and a timeout-isolated read-only
   worker. Test repeated and concurrent requests, deadlines and failures.
7. Integrate after saved edit attribution and coalesce context through existing
   transport collection. Test direct Claude JSON and all five adapters.
8. Measure callback/worker cost and installed no-model startup if supported;
   publish which paths were actually exercised and leave unqualified exits open.
9. Perform one fresh whole-branch review, repair important findings with witnessed
   regressions, and update user/contributor guides, status, plan and journey.
10. Refresh architecture and CI imports; render all views, run appropriate
    regression/doctor/grader checks and exact-head hosted matrix. Integrate the
    verified branch into main under existing authorization and verify publication.

Interfaces: evaluator consumes the existing report/recheck schema; policy owns
all limits; reservations precede worker launch; hook integration consumes only
bounded text; transport serialization stays host-owned. No report changes may
promote an incomplete receipt or treat advice as proof.
