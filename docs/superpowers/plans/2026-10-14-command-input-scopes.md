# Command-scoped witnesses and shared evidence collection

**Goal:** preserve independent check evidence without hiding relevant drift, and
reduce repeated external reads in nested reports. Build for arbitrary projects.

**Execution:** inline in the existing clean checkout on
`codex/command-input-scopes`; deliver descriptive incremental pushes and main.

1. Rehearse actual two-command Python/JavaScript consumers and witness failing
   regressions for declaration recognition, independent freshness and broad fallback.
2. Add strict opt-in schema 2 mappings and scope projections. Preserve schema 1
   parsing, serialization and broad receipts. Validate hostile and ambiguous input.
3. Bind native and owned execution, confirmation and PatchProof saved associations
   to declared command scopes; retain source/task/configuration/producer guards.
4. Share bounded opening/closing external observations across nested reports,
   without sharing source snapshots or command execution phases. Test closing drift,
   failed coverage, cross-root isolation and read counts.
5. Add portable multi-task protocol and qualified explanations. Rehearse locally;
   run at most the separately approved installed allowance if granted.
6. Request one fresh whole-branch review, regrade all findings, repair important
   defects once with witnessed regression and full verification.
7. Freeze runtime; run full suite, named audits, independent grader/reproduction,
   doctor, stdlib checks and hosted matrix/artifact. Record measured limits.
8. Update README, guides, plan/status, research, validation and journey; refresh
   all five architecture views and render. Verify publication, integrate main.

No command is removed from required verification. Unknown/partial declarations
retain broad coverage. Earlier model allowances do not authorize new sessions.
