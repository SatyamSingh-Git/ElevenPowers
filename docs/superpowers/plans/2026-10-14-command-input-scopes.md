reduce repeated external reads in nested reports. Build for arbitrary projects.

`codex/command-input-scopes`; deliver descriptive incremental pushes and main.

   without sharing source snapshots or command execution phases. Test closing drift,
   failed coverage, cross-root isolation and read counts.
5. Add portable multi-task protocol and qualified explanations. Rehearse locally;

6. Request one fresh whole-branch review, regrade all findings, repair important
   defects once with witnessed regression and full verification.

   doctor, stdlib checks and hosted matrix/artifact. Record measured limits.
8. Update README, guides, plan/status, research, validation and journey; refresh
   all five architecture views and render. Verify publication, integrate main.

retain broad coverage. Earlier model allowances do not authorize new sessions.
