## General repairs and producers

Measure existing graph paths first. Add optional TypeScript compiler resolution
where compiler semantics are needed for config aliases, exports and imported
callable bindings. Use an explicitly selected, version-qualified trusted engine,
bounded subprocess execution and virtual selected source inputs. Do not execute
project configs or source during a graph query. Existing tree-sitter remains the
lightweight default; unsupported compiler versions or relationships stay gaps.

Add offline conversion of actual coverage.py contexts and Node V8 coverage into
the existing observation contract. A producer/run receipt must bind source
fingerprints before and after execution and state exit/completion independently
of coverage contents. Contextless Python data, unmapped Node locations and
unattributed runs cannot invent test relationships. Executed lines are observed
relationships, not assertions or proof of correctness. Explicit collection is
separate from ordinary read-only queries and never runs on installation.

Static adapter omissions and incomplete input selection are different. Current
complete capture may add trustworthy-in-scope local relationships even when
another static adapter reports unresolved semantics; unread source, invalid
declarations, stale fingerprints and incomplete producers remain disqualifying.
Preserve unsigned-report qualifications and whole-query coverage gaps.

## Measurements and automatic integration

Report known consumer/test recall, explicit negative witnesses, unlabelled leads,
qualified-fault detection, selected/full relevant test execution, build/query
elapsed samples, coverage issues and every attempted producer outcome. Separate
file-wide conservative queries from more specific symbol or observed paths.
Do not treat total passing checks as a gain or compare unequal test scope as
speedup. Full relevant suites are named and bounded, not silently called every
test in an upstream repository.

Proposed held-out exit: at least 90% detection of qualified faults caught by the
full relevant suite, with every miss published. Small denominators and authored
faults remain explicit. Automatic advisory integration additionally needs useful
recommendation/noise measurements and bounded ordinary-session overhead. If
those requirements are not met, publish the failed exit and leave automatic
queries pending. Do not add a completion blocker or turn an absent path into a
safety certificate. No model/paid evaluation sessions are part of this work.
