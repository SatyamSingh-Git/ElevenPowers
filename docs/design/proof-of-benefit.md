# A completion decision with observable consequences

The next delivery tests whether an existing ElevenPowers mechanism improves a
coding or verification outcome. Task size is immaterial. A positive result must
link a real proposed completion, a plugin action, and independently checked
subsequent behavior. Neutral and negative results remain results.

First diagnose native delivery on one installed subscription host. A configured
hook is insufficient; observe startup, edit, command and completion callbacks.
Do not bypass host trust or silently substitute a model/provider. Fix runtime
behavior only after reproducing its cause. Unavailable host cells remain open.

Use two frozen tasks (a stale-check opportunity and a correct control), two arms
and two repeats on that host: eight coding calls maximum, four minutes each.
The baseline and treatment receive the same issue, source, tests, normal context,
tools, model and effort. Only the ordinary plugin intervention differs. Do not
instruct the agent to skip verification to manufacture a favorable result.
Counterbalance order. Codex uses gpt-6.1-sol medium; Claude uses
claude-sonnet-5-5 medium. Authentication must be subscription based, never API.

A neutral recorder is installed in both arms. It captures each proposed Stop
before intervention, without changing the Git index, candidate source or host
decision. Snapshot only explicitly frozen task files; bound files, bytes and
records, reject links, and retain unavailable/incomplete observations. Keep
candidate source outside ordinary product exports. Grade snapshots outside the
candidate workspace using a sealed evaluator; report initial, proposed and final
behavior alongside native receipt freshness and the actual decision. A callback
counter alone cannot establish a causal effect.

Borrow the existing subscription runner, process containment, native wiring,
checkpoint concept and independent grading patterns. Add controlled proposal
measurement and a new protocol; preserve the original pilot unchanged. Generalize
every runtime fix and recorder path. Snag is never a runtime policy.

Before model use run free forward and adversarial controls, then one native
acceptance exercise. Failed native delivery or capacity prevents the batch and
must produce a retained blocked result and exact resumption instructions. Freeze
the protocol before calls; retain all attempts, including setup and quota errors.
Publish reproducible evidence and bounded claims. This pilot cannot establish a
population effect, productivity gain, security boundary or cross-host support.
