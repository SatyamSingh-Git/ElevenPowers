# Declared-check adoption and batches — validation

Status: generalized guidance and owned batches are implemented and pushed.
The fresh review found one Important frozen-selection race; its three controls
failed as expected and the repair passes 75 affected controls in 76.02 seconds. Full
local/hosted source qualification and fresh installed adoption remain pending.
The user has given standing authorization for needed Sonnet 5.5 medium
subscription sessions; no new model session has run in this work yet.

## What changed

Property labels sit outside encoded shell commands. Startup and explicit new
verification tasks show readable arguments and a single all-declared-check
invocation. No-edit advice invents no claim and launches no child. Filtered
recheck advice stays narrow; ordinary continuations, duplicates and off retain
their existing behavior. Startup no longer promises all verification will
automatically run at completion.

The explicit `ep_check.py --all` executes every supported effective declaration
under one owner and deadline. Each property keeps its actual outcome and separate
source/input/configuration/producer qualification. Failures continue independent
checks; deferred selections and interruption remain visible. Frozen command and
context guards prevent changed declarations from becoming a new accepted baseline.

AST inspection confirms no unqualified static local helper imports remain.
Full execution is restarted with immediate failure diagnostics after that repair.
