# Changelog

## Unreleased

- `Client.options()` for sending preflight requests.

## 0.4.0

- Pagination helper `paginate()` with `next` and `prev` links.
- `access_log` middleware.
- `App(debug=True)` lets unexpected exceptions propagate.

## 0.3.0

- `Router.include()` mounts one router under a prefix of another.
- `url_for` refuses values the parameter type would not match.
