# Changelog

## Unreleased

- `gradebook what-if` shows the class's grades under different category weights.

## 0.9.0

- Term calendars: `gradebook day` and `gradebook date` convert between dates and term days.
- `gradebook archive` writes a repeatable end-of-term zip file.
- LMS gradebook exports import with `gradebook import lms`.
- Report cards, the late work report and `gradebook explain`.

## 0.8.0

- Score sheets: `gradebook sheet` writes one, `gradebook import sheet` reads it back.
- Transcripts from posted term grades files.
