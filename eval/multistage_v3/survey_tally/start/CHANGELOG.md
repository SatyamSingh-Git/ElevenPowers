# Changelog

## Unreleased

- `surveytally status` shows what a project folder holds.

## 0.9.0

- Banner tables (`surveytally banner`) and significance letters for cross-tabulations.
- `--where` narrows any analysis command to a subgroup.
- Open-ended answers can be coded with a keyword codeframe (`surveytally code`).
- Response files can be JSON lines as well as CSV.

## 0.8.0

- Raking over several target questions, with weights trimmed between a floor and a cap.
- `surveytally compare` reads two exported frequency tables and reports the change.
- Quality flags for straightliners and respondents who skip most questions.
