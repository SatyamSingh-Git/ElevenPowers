# greenhouse

Monitoring for a commercial greenhouse: controller exports go into a readings
log, and the commands turn that log into daily summaries, alerts, irrigation
suggestions and a valve schedule.

```
greenhouse --data /srv/greenhouse --now 2026-05-01T06:00:00 ingest export.csv
greenhouse --data /srv/greenhouse --now 2026-05-01T06:05:00 check
greenhouse --data /srv/greenhouse --now 2026-05-01T06:05:00 irrigate
greenhouse --data /srv/greenhouse --now 2026-05-01T06:05:00 schedule
greenhouse --data /srv/greenhouse --now 2026-05-01T20:00:00 report
```

The scheduler passes `--now`; nothing reads the wall clock. Every option,
setting, message and file format is listed in `docs/reference.md`.

## Layout

- `src/greenhouse/core` - records, units, time and errors
- `src/greenhouse/config` - settings, zone layout, thresholds, crops
- `src/greenhouse/storage` - the readings log, alerts log, calibration, plan and archive files
- `src/greenhouse/services` - import, alerts, statistics, irrigation, light and climate
- `src/greenhouse/reports` - text, CSV and JSON output
- `src/greenhouse/cli` - the `greenhouse` command

`src/greenhouse/_generated.py` is the vendor sensor catalog, regenerated by the
catalog export job.
