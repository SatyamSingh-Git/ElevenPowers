# Changelog

## Unreleased

- `clinic handover` prints the evening note for the next open day.

## 1.4.0

- `clinic sheets` writes every working practitioner's day sheet to a folder.
- Backups of the bookings file before each change; `clinic backups` and `clinic restore`.
- `clinic patients --out` writes the patient directory as CSV.

## 1.3.0

- Waiting list: `clinic wait`, `clinic waiting`, `clinic offers` and `clinic unwait`.
- `clinic import` books the online booking partner's nightly file.
- `clinic book --weeks` books a weekly course in one go.

## 1.2.0

- Room utilisation from an exported day schedule: `clinic utilisation`.
- Patient statements from the charges file: `clinic statement`.
