# 66 — Earlier behavior needs a second task

The next question was whether the existing graph, milestone receipts and bounded
advice help when development continues. Four approved subscription sessions
worked on the same two authored systems: queue leases followed by persistence,
and inventory expiry followed by persistence. Each pair started with identical
working source and public checks, used Sonnet 5 medium and had eight minutes per
resumed session. Private checks stayed outside candidates and supplied no
feedback between requests.

The first thing the review improved was our evaluator. Losing restored payloads,
returning Python objects instead of JSON and forgetting expiry inside reserve
could escape the original checks. Resumed callback identity and mutable loaded
budgets also needed stronger qualification. Original observations were retained;
unstarted slots received corrected protocols, and saved source was regraded
without extra model calls. A later archive check made a separate distinction:
correctly grading a source file does not make its experimental protocol comparable.

Every first-stage output passed six corrected independent groups, and every
final output passed eight. Both pairs tied. The ordinary runs already preserved
the tested behavior, so this experiment supplies no example of a regression
ElevenPowers repaired. Assisted host times were higher in both observations;
the selected sample cannot separate model variation from runtime cost.

Installed callbacks gave useful operational evidence. Both assisted sessions
processed startup, prompt, edits and completion. Five workers retained three
delivered contexts and two incomplete attempts. But the agents wrapped test
commands in `cd PROJECT &&`, and no exact declared-command native links were
recorded. Completion verification made milestone reports current, which is
different evidence from native command capture. Post-tool context bodies were
not exposed by the stream, so runtime delivery is not proof of model consumption.

The next step is concrete: qualify ordinary invocation forms and advice
consumption without weakening command identity, and retain independent broader
relevance controls. More model calls should answer a specified open question;
these two correctness ties do not justify default activation or a benefit claim.
