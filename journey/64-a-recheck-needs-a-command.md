# 64 — A recheck needs a command

2026-10-07.

Earlier behavior survives task changes in the ledger. A dependency path still
leaves someone to work out what to run. This delivery joins paths to exact
project commands, deduplicates shared checks and preserves every milestone's
evidence state. Ranking cannot make stale evidence current or drop another check.

The controller freezes six small project scenarios, required relationships,
unrelated references and assertions. Five of six required relationships produce
leads; the subprocess worker does not. Its fallback catches the CLI fault.
Calling that a recovered relationship would hide the gap we need to improve.
Thirty-six actual runs give thirty passes and six assertion failures. Equivalent
code passes and checks stay unchanged. An unrelated edit creates no lead while
broad native receipts still expire: ranking is not precise invalidation.

Fifty-four paired reads show median added local cost of 82.05 ms, on only four
to nine selected files. This does not predict large-repository or native callback
cost. No model runs or incremental coding improvement were measured.

An unchanged-source control caught a fingerprint comparison mistake: graph and
evidence identities use different formats. We now derive a common content
identity from actual graph input bytes. A separate control ensures explanation
truncation cannot pass the explicit requested-coverage gate.
