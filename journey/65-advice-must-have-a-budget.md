# 65 — Advice must have a budget

The prior milestone made recheck ordering explicit. The next question was whether
it belonged in the editing loop. Three source-sealed upstream snapshots gave a
different cost picture from tiny authored examples: six selected required leads
were recovered, but every report retained static gaps and paired reads added a
median 947.254 ms. That is a real interruption when repeated after every edit.

The experiment also exposed a label mistake. Different test behaviors were
initially called unrelated, even though package initialization/transitive paths
can connect them. We withdrew those negative labels, retained the original
corpus/results, and kept four cross-reference leads unknown. No precision figure
or coding-quality gain follows from six recovered references.

Known process boundaries need no new speculative parser: project-owned
`impactgraph.json` edges already represent them with declared provenance. A
real CLI test accepted the original and equivalent output and rejected the
fault, while the unrelated authored check stayed fallback.

Automatic delivery therefore uses an explicit opt-in and a separate worker.
Atomic reservations precede inspection, repeated observations are suppressed,
cooldown and per-task allowances bound retries, and incomplete work remains
diagnostic state. The shared post-edit flow combines advice, guidance and native
attribution gaps into one response. No receipt or completion status is changed.

Across 135 replay launcher processes, there were no nonzero exits or duplicate
advice; median added delay was 1282.703 ms. All advised contexts were incomplete;
44 workers delivered context and one attempt was incomplete. Installed Claude
2.1.287 separately processed startup without a prompt. That is not installed
edit advice acceptance, and replay is not native-session evidence.

Next freeze independently justified negative references, qualify installed edit
and completion sessions under agreed model budgets, and only then consider
default activation and the matched end-to-end comparison. See
[results](../results/milestone-advisories/README.md),
[callback limits](../results/milestone-advisories/callbacks.md) and
[validation](../docs/validation/2026-10-07-milestone-advisories.md).
